      How much smaller?

      Get it under
      Scans and photo-heavy PDFs shrink the most. A PDF that is mostly text is already small and may barely change. If compressing can't make the file smaller, you get the original back unchanged. A very small target may not be reachable without the pictures becoming unusably soft — the tool tells you the smallest it could manage.
      Quick start
      1. Open your PDF with the file box at the top of the page. Edit PDF, Fill a form and Compress all work on the PDF you open there. (New from template does not need one.)
      2. Pick a tab for what you want to do.
      3. Make your changes. Nothing is saved to your original file.
      4. Press Build PDF / Fill PDF / Generate PDF / Compress. A preview of the result appears below the button.
      5. Press Download to save it. In the Windows app a Save box asks where to put it.
      Not happy with the result? Change something and press the build button again. Your original PDF is never altered, so you can repeat as often as you like.
      Want to do more to that same result — for example fill a form, then add a stamp? See "Combining tools on one result" below.

      The four tools at a glance

      TabUse it to
      Edit PDFType Dhivehi or English anywhere on a PDF, add a signature, add stamps (ready-made, custom text, or your own picture).
      Fill a formFill in PDF forms that have fillable fields, including with Dhivehi.
      New from templateCreate a new PDF (for example an official letter) from a template.
      CompressMake a PDF smaller so it is easier to email or upload.
      Combining tools on one result

      Every result — a filled form, an edited PDF, a generated letter, a compressed file — has a ✎ Continue editing this PDF → button next to its Download button. Pressing it opens that exact result as the PDF you are working on and switches to Edit PDF, so you can carry straight on instead of saving a file and opening it again.

      This is how you combine tools that live on different tabs, for example:

      • Fill a form, then press ✎ Continue editing this PDF → to add a signature or a stamp to the filled form.
      • Generate a letter from a template, then continue editing it to sign it.
      • Edit or sign a PDF, then continue editing again to add a date stamp, or switch to Compress to shrink the final result.
      Compress last. If you add more text, a stamp or a signature after compressing, run Compress again afterwards — new additions are not covered by an earlier compress.

      Your original uploaded PDF is never changed by any of this. Each press of the button works on a fresh copy, so if a chain of edits goes wrong you can always start over by opening the original file again at the top of the page.

      Edit PDF: adding text

      Add a text box

      • Use ◀ ▶ to go to the page you want.
      • Drag a rectangle on the page where the text should go, or just click once to drop a box of standard size.
      • Type your text in the Text box on the right. Dhivehi and English can be mixed. Press Enter for a new line.

      Move, resize, delete

      • Move: drag the box.
      • Resize: drag the small orange square in its bottom-right corner.
      • Delete: select it and press Delete in the panel on the right.
      • The list Everything on this PDF shows all your items. Click one to select it, even if it is on another page.

      Edit PDF: signatures
      1. Press ✍ Signature.
      2. Draw with your mouse, finger or pen (choose black, blue or red ink and the thickness; Clear to start again), or open Upload a picture and choose a photo or scan of your signature. Keep Make the white background transparent ticked so that only the ink shows.
      3. Leave Keep this signature on this computer ticked if you want it saved for next time. Saved signatures appear at the top of the box; click one to use it, or the small ✕ to forget it.
      4. Press Place on page. The signature appears in the middle of the current page. Drag it into position and drag its corner to resize (proportions are kept). Use Tilt to rotate it slightly.
      To sign every page of a document (for example initials), set Put it on to All pages. To add a name or date under the signature, add a normal text box.
      This adds a picture of your signature to the PDF. It is not a certificate-based digital signature and cannot be verified electronically.
      Edit PDF: stamps (ready-made, custom, picture)

      Ready-made and custom text stamps

      1. Press ▣ Stamp ▾ and choose one (APPROVED, REJECTED, RECEIVED, PAID, CONFIDENTIAL, URGENT, FOR REVIEW, DRAFT, COPY), or Custom text….
      2. The stamp appears in the middle of the page. Drag to move, drag the corner to resize.
      3. In the panel on the right you can change the text (Dhivehi works), font, colour, tilt, turn the border on or off, and add a date line (type any date text you like, for example 20 Sep 2026).

      Use your own picture as a stamp (seal, logo, scanned stamp)

      1. Press ▣ Stamp ▾ then 🖼 Import a picture….
      2. Choose a PNG or JPG. Keep Make the white background transparent ticked.
      3. Press Place on page, then move, resize and tilt it. Imported pictures are kept in the Stamp menu for next time (click ✕ on a thumbnail to remove one).
      A clear picture on a plain white background works best. If the picture has a coloured or grey background, crop it tightly first, or untick the transparency option.

      Add your own stamp names

      Open the file stamps.json (in the app folder) in Notepad and add lines such as {"name": "Label", "text": "Text on the stamp", "color": "#15803d"}. Dhivehi text is fine. Restart the tool to see the changes.

      The stamp you see on screen is an approximation. The finished PDF centres and fits the text exactly. Check the preview after pressing Build PDF.
      Fill a form
      1. Open a PDF that has fillable form fields, then go to Fill a form.
      2. The page is shown on the left with every field outlined directly on it. Click a field on the page (or click it in the list on the right) and type. Fields you do not touch stay as they are.
      3. Use ◀ ▶ to move between pages; the field list on the right shows every field with its page number, so you can jump to one that is on another page.
      4. Choose a Font for Dhivehi entries. Optionally set a font size (leave it blank for automatic).
      5. Press Fill PDF, check the preview and Download.
      Need to sign or stamp the filled form too? No need to save it first — press ✎ Continue editing this PDF → next to Download and it opens straight into Edit PDF with everything you just filled in still there.

      When a form is not built well

      Some PDF forms have fields that are too small to see or click, placed slightly off from the box printed on the page, or the same field name reused in more than one spot. The tool marks these for you so filling them is not guesswork:

      • Outlined in red, "too small in this PDF": the field's clickable area is too tiny to use comfortably (or sits outside the visible page). A Type here instead → button appears on it — this switches to Edit PDF and drops a normal, resizable text box in the same spot, which you can then position exactly and type into.
      • "SAME EVERYWHERE": this field name is used in more than one place in the PDF. Whatever you type goes into all of those places at once, because that is how the form was built — there is no way to give each spot different text through the form field itself. If you need different text in each spot, use Edit PDF for the extra ones instead.
      • Dhivehi in a field: PDF form fields cannot show Thaana on their own. The tool draws your Dhivehi text as correct, shaped text over the field and removes that field, so that one field can no longer be edited afterwards.
      • English, numbers and tick boxes stay as normal editable fields.
      • Flatten makes every field non-editable, so the form looks like a printed page.
      If the tool says the PDF has no fillable fields at all (this is common with scanned forms), use Edit PDF and type directly onto the page instead.
      New from template
      1. Open New from template and choose a template (an official letter is included).
      2. Choose the Font and fill in the boxes. In the letter, each line of the Body becomes its own paragraph.
      3. Tick Page numbers if you want them, then press Generate PDF. Long text automatically flows onto more pages.

      The small label boxes (for example Reference, Date and Subject labels) are pre-filled in Dhivehi and can be changed to anything you like.

      Adding your own templates

      • Templates live in the pdf_templates folder next to the app. Copy letter.html and letter.json and edit the copies in Notepad. Use {{ name }} for the parts that change. The form on screen is built from these automatically.
      • <p{{ text|attrs }}> gives a paragraph the right direction and size for Dhivehi or English; {{ body|paragraphs }} turns multi-line text into paragraphs.
      • The .json file sets the field names, labels, defaults, and page margins.
      Have a Dhivehi speaker check the default label wording in the letter template before official use.

      To add a signature or stamp to the letter you just generated, press ✎ Continue editing this PDF → next to Download — it opens the generated letter straight into Edit PDF.

      Compress
      1. Open a PDF, go to Compress. The current file size is shown.
      2. Choose how much smaller:
        • Light: hardly any visible change, modest savings.
        • Balanced: good for email and uploads (recommended).
        • Strong: smallest file; pictures become softer.
      3. Optional: Convert images to greyscale (saves more space) and Remove metadata (title, author and similar hidden information).
      4. Press Compress. The result shows the size before and after.
      Scans and photo-heavy PDFs shrink the most. A PDF that is mostly text is already small and may barely change. If compressing cannot make the file smaller, you get the original back unchanged.

      To compress a PDF you have just edited, filled in, or generated, there is no need to download and re-open it first: build that result, then press ✎ Continue editing this PDF → next to its Download button, then switch to Compress. Do this last, after signing or stamping — compressing first and then adding more on top can undo some of the size saving.

      Fonts
      • Every tool has a Font menu with a sample line in the chosen font, so you can see the look before using it.
      • The menu lists the built-in Noto Sans Thaana, any font you have added, and Thaana fonts already installed on your computer (on Windows, for example, Faruma or MV Boli).
      • In Edit PDF each text box and stamp can have its own font. In Fill a form and New from template one font is used for the whole result.
      • Add a new font: press Add font… and choose a .ttf or .otf file. It must contain Thaana letters, otherwise the tool tells you it cannot be used. Added fonts are kept in the fonts folder next to the app.
      • Bold: works when the font has a bold file beside it (for example Faruma.ttf with a matching bold file). Otherwise Bold makes no difference for that font.
      • Size differs by font: some fonts draw Dhivehi larger or smaller than others at the same point size. In Edit PDF, adjust the size. Letter templates are tuned for Noto Sans Thaana, so other fonts may look a little smaller or larger.
      Typing Dhivehi (Thaana keyboard)
      • If your computer already has a Dhivehi keyboard, just type as normal in any text box.
      • If not, press ދ Thaana keyboard at the top right. Click in a text box, then tap letters on the on-screen keyboard. The vowel signs (fili) are shown on the letter އ so you can see them; only the sign itself is inserted.
      • The on-screen keyboard also has the Dhivehi comma, question mark, a space and a new line.
      • Numbers and dates: after Dhivehi text, numbers such as 19 September 2026 are kept in the right order automatically.
      Saving, privacy and where things are kept
      • Your files stay on your computer. Nothing is sent to the internet.
      • To work on your PDF, the tool keeps a temporary copy in your computer's temp folder. Copies older than about 6 hours are deleted automatically (checked when the app starts and when you open a PDF).
      • Saved signatures and stamp pictures are remembered on this computer only. On another computer, add them again.
      • Your original PDF is never changed. Every result is a new file that you save yourself.
      • Editable extras next to the app: pdf_templates (templates), stamps.json (stamp list), fonts (added fonts).
      What this tool does not do
      • It adds text, signatures and stamps to a PDF. It does not edit or delete the existing text or pictures already in a PDF.
      • It does not create certificate-based digital signatures.
      • It cannot open password-protected PDFs. Remove the password in another program first.
      • It does not read text from scanned pages (no OCR).
      • Very large files (over about 100 MB) cannot be opened.
      Troubleshooting
      ProblemWhat to try
      Dhivehi letters show as empty boxes or look wrongPick a Thaana font from the Font menu. Some other fonts have no Thaana letters at all.
      Text is smaller than expectedTurn off Shrink to fit, make the box bigger, or raise the size. Dhivehi usually needs a larger point size than English.
      "Text does not fit in its box" messageMake the box bigger, lower the size, or turn on Shrink to fit.
      Nothing appears in the PDFCheck the item is on the page you expect and that it has text (empty text boxes are skipped). Press Build PDF again.
      The stamp looks slightly different on screen than in the PDFThe on-screen stamp is a quick approximation. The PDF preview after Build PDF is the real result.
      "This PDF has no fillable form fields"Use Edit PDF and type directly onto the page.
      A form field is too small to click, or in the wrong placeUse the red "Type here instead" button on it in the Fill a form page — it adds a normal, movable text box in Edit PDF at the same spot.
      Filling one field also fills another oneThe PDF form reuses the same field name in both places (marked "SAME EVERYWHERE"). Fill it once for the shared value, and use Edit PDF to add separate text for a spot that needs to say something different.
      "That PDF has expired, please upload again"Open the PDF again with the file box at the top.
      The app does not start, or is very slowMake sure the whole folder is on your own computer (Desktop or C:\), not on the office server or a shared drive. Keep DhivehiPDF.exe inside its folder.
      Windows says "Windows protected your PC"Click More info, then Run anyway. If it is blocked, ask IT to allow the DhivehiPDF folder.
      The app opened in a web browser instead of its own windowEverything still works the same way there - keep the small message box open while you work, and click OK on it when you finish to close the tool. This almost always means the Microsoft Edge WebView2 Runtime isn't installed on this computer; the message box tells you when that is the reason and links to the installer. Install it, restart DhivehiPDF.exe, and the tool will open in its own window. If the message doesn't mention WebView2, a file called window_error.log appears next to DhivehiPDF.exe with the details - send that to whoever supports the tool.
      Installing and starting the Windows app
      1. Copy the whole DhivehiPDF folder to your own computer (Desktop or a local drive such as C:\). If it arrived as a zip file, right-click it and choose Extract All first.
      2. Open the folder and double-click DhivehiPDF.exe. The first start can take a little while.
      3. For an easy shortcut: right-click DhivehiPDF.exe, choose Send to, then Desktop (create shortcut).
      Do not run it from the office server or any shared/network folder. It will not work properly there. Always copy the whole folder to your own computer first.
